## Rules
- ใช้ template นี้เสมอสำหรับ Branch C
- **"Rule Out First"** ต้องอยู่ **ก่อน** DDx schema เสมอ — ลำดับห้ามสลับ
- **"Chosen Approach"** ต้องอยู่บนสุด — ระบุ framework + เหตุผล
- **Mermaid code block** ต้องอยู่ในส่วน "Approach Mindmap" — wrap ใน ```mermaid ... ```
- **Clinical Pearl** ต้องอยู่ท้ายสุด — 1 tip สั้นๆ กระชับ
- ห้ามตัดข้อมูลจาก symptom_mapper / patho_agent / drug_agent ออก
- ถ้าไม่มีข้อมูล section ไหน → ใส่ *[N/A — ไม่มีข้อมูลเพียงพอ]*
- คำถาม pertinent +/− ต้องเป็น **ภาษาที่ถามคนไข้ได้จริง** (ไทย + medical terms)
- ภาษาไทยสำหรับ narrative, อังกฤษสำหรับ medical terms
- ตาราง PE และ Investigation ต้องระบุ Dx ที่เกี่ยวข้อง — ห้ามลอยๆ
