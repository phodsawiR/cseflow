## 1. การวินิจฉัย

### 1.1 ECG
> **ทำภายใน 10 นาที** หลัง first medical contact — Class I

| Pattern | ความหมาย |
|---|---|
| ST elevation ≥1mm ใน ≥2 contiguous leads | STEMI |
| New LBBB | STEMI equivalent |
| De Winter pattern | LAD occlusion equivalent |
| Wellens syndrome (biphasic/deep T inversion V2–V3) | Critical proximal LAD stenosis |

---

### 1.2 High-Sensitivity Troponin (hs-cTn)
> ใช้เป็น **primary biomarker — Class I**
> ⚠️ **Delta troponin สำคัญกว่า absolute value เดี่ยวๆ**

| Protocol | Timepoints | เงื่อนไข |
|---|---|---|
| **0h / 1h** *(Preferred)* | เก็บที่ 0 และ 1 ชั่วโมง | ใช้ hs-cTnI ที่ validated แล้ว |
| **0h / 2h** | เก็บที่ 0 และ 2 ชั่วโมง | Alternative |
| **0h / 3h** | เก็บที่ 0 และ 3 ชั่วโมง | Conventional troponin |

---

### 1.3 Risk Stratification Tools
- **HEART Score** — ใช้ใน ED สำหรับ chest pain triage
- **TIMI Score** — ประเมิน 14-day mortality/MI risk
- **GRACE Score** — ประเมิน in-hospital และ 6-month mortality ใน NSTEMI

---

### 1.4 Imaging
| Modality | Indication | Class |
|---|---|---|
| **Echocardiography** | Wall motion abnormality, EF assessment | I |
| **CCTA** | Low–intermediate risk, equivocal troponin | IIa |

## 2. STEMI vs NSTEMI — Overview

| | **STEMI** | **NSTEMI / UA** |
|---|---|---|
| **ECG** | ST elevation / New LBBB / Equivalents | ST depression, T inversion, หรือ normal |
| **Troponin** | Positive (อาจ negative ใน hyperacute) | Positive (NSTEMI) / Negative (UA) |
| **Mechanism** | Complete occlusion | Partial occlusion / plaque erosion |
| **Reperfusion goal** | **≤90 min** (D2B) / ≤120 min (FMC2B) | Risk-stratified (2h / 24h / 72h) |
| **Fibrinolysis** | ✅ ถ้า PCI ไม่ทันเวลา | ❌ ไม่แนะนำ |
| **Primary strategy** | Primary PCI | Invasive vs conservative ตาม risk |

## 3. การรักษาเฉียบพลัน

### 3.1 STEMI — "Time is Muscle"

```
🎯 Door-to-Balloon (D2B)           ≤ 90 นาที   (Class I, LOE: A)
🎯 First Medical Contact-to-Balloon ≤ 120 นาที  (Class I, LOE: A)
```

| สถานการณ์ | กลยุทธ์ |
|---|---|
| PCI-capable hospital | **Primary PCI ทันที** |
| Non-PCI hospital — transfer ≤120 min | **Transfer for Primary PCI** |
| Non-PCI hospital — transfer >120 min | **Fibrinolysis → transfer ภายใน 24h** |

> **⚠️ Fibrinolysis:** ใช้ Tenecteplase / Alteplase — ถ้าให้แล้ว ต้อง transfer ทุกราย ภายใน 3–24h

---

### 3.2 NSTEMI/UA — Risk-Stratified Invasive Strategy

| Risk Level | เกณฑ์ | กลยุทธ์ |
|---|---|---|
| **Very High Risk** | Hemodynamic instability, Refractory ischemia, Mechanical complication | **Invasive ≤ 2 ชั่วโมง** |
| **High Risk** | GRACE >140, Dynamic ECG change, Dynamic troponin rise | **Invasive ≤ 24 ชั่วโมง** |
| **Intermediate Risk** | GRACE 109–140, DM, CKD, EF <40% | **Invasive ≤ 72 ชั่วโมง** |
| **Low Risk** | ไม่มีปัจจัยข้างต้น | **Conservative / Stress test ก่อน discharge** |

## 4. ยาที่แนะนำ

### 4.1 Antiplatelet — DAPT
> **Dual Antiplatelet Therapy = Aspirin + P2Y12 inhibitor**

| ยา | Loading dose | Maintenance | Class | หมายเหตุ |
|---|---|---|---|---|
| **Aspirin** | 162–325 mg | 75–100 mg OD | I-A | ทุกราย ACS |
| **Ticagrelor** ⭐ | 180 mg | 90 mg BID | I-B | **Preferred** — ทุก ACS |
| **Prasugrel** | 60 mg | 10 mg OD | I-B | เฉพาะผู้ที่ทำ PCI — **ห้ามใช้ถ้ามี stroke/TIA hx** |
| **Clopidogrel** | 600 mg | 75 mg OD | I-A | ใช้เมื่อ Ticagrelor/Prasugrel **contraindicated** |

> **🔑 Key Update 2023:** Ticagrelor preferred over clopidogrel อย่างชัดเจนในทุก ACS

**Duration of DAPT:**
- **Post-PCI with DES:** 12 เดือน (standard)
- **High bleeding risk:** อาจลดเป็น 3–6 เดือน (Class IIa)
- **Post-CABG:** Aspirin ตลอดชีวิต + Ticagrelor 1 ปี (Class IIa)

---

### 4.2 Anticoagulation

| ยา | Setting | Class |
|---|---|---|
| **UFH** (Unfractionated Heparin) | STEMI — Primary PCI | I-C |
| **Enoxaparin** | NSTEMI / STEMI (ทั้ง PCI และ conservative) | I-A |
| **Bivalirudin** | High bleeding risk ระหว่าง PCI | IIa-A |
| **Fondaparinux** | NSTEMI — Conservative strategy | I-B |

> ⚠️ **ห้ามใช้ Fondaparinux เป็น sole anticoagulant ระหว่าง PCI** — เสี่ยง catheter thrombosis

---

### 4.3 ยาอื่นๆ ที่จำเป็น

| กลุ่มยา | ยา | Indication | Class |
|---|---|---|---|
| **Beta-blocker** | Metoprolol / Carvedilol | EF <40%, ทุก ACS (ถ้าไม่ CI) | I-A |
| **ACEi / ARB** | Ramipril / Valsartan | EF <40%, HF, DM, HTN | I-A |
| **High-intensity Statin** | Atorvastatin 40–80mg / Rosuvastatin 20–40mg | ทุกราย ACS | I-A |
| **Ezetimibe** | Ezetimibe 10mg | LDL ยังสูงหลัง max-dose statin | I-B |
| **PCSK9 inhibitor** | Evolocumab / Alirocumab | LDL ไม่ถึงเป้า **<55 mg/dL** | I-A |
| **SGLT2i** | Empagliflozin / Dapagliflozin | ACS + T2DM (HF prevention) | I-A ⭐ **(NEW)** |
| **GLP-1 RA** | Semaglutide / Liraglutide | ACS + T2DM + Obesity | I-A ⭐ **(NEW)** |
| **Colchicine** | Colchicine 0.5mg OD | ลด residual inflammation | IIb **(NEW)** |

## 5. Intervention

### 5.1 PCI — Key Principles

| หัวข้อ | คำแนะนำ | Class |
|---|---|---|
| **Vascular Access** | **Radial > Femoral** — ลด bleeding / vascular complication | **I** ⬆️ |
| **Stent Type** | **Drug-Eluting Stent (DES)** preferred over BMS | I |
| **Complete Revascularization** | Staged PCI ใน non-culprit lesion ใน STEMI + multivessel disease | **IIa** ⬆️ |
| **FFR / iFR Guided** | ใน non-culprit lesion ที่ intermediate stenosis | IIa |

---

### 5.2 CABG — Indications

```
✅ Multivessel disease + Complex anatomy (SYNTAX score >22)
✅ Left main disease (≥50% stenosis)
✅ ACS + DM + Multivessel disease (ถ้า anatomy เหมาะสม)
⏱️ Timing: ≥24h หลัง stabilization ใน NSTEMI
```

---

### 5.3 Mechanical Circulatory Support (MCS)

| Device | Indication | Class |
|---|---|---|
| **IABP** (Intra-aortic Balloon Pump) | Cardiogenic shock ที่ไม่ตอบสนองต่อยา | **IIb** ⬇️ |
| **Impella** | Refractory cardiogenic shock ระหว่าง PCI | IIb |
| **VA-ECMO** | Refractory cardiogenic shock / cardiac arrest | IIb |

> ⚠️ **IABP ลด class จาก IIa → IIb** เนื่องจากหลักฐาน (IABP-SHOCK II trial) ไม่พบว่าลด mortality

## 6. สิ่งที่เปลี่ยนแปลงจาก Guideline เดิม

| หัวข้อ | 🔙 เดิม (2014/2021) | 🆕 ใหม่ (2023) | ทิศทาง |
|---|---|---|---|
| **Troponin Protocol** | 0 / 3 / 6 ชั่วโมง | **0 / 1h หรือ 0 / 2h** ด้วย hs-cTn | ⚡ เร็วขึ้น |
| **P2Y12 Inhibitor** | Clopidogrel ยังใช้ได้เทียบเท่า | **Ticagrelor/Prasugrel preferred** อย่างชัดเจน | ⬆️ ยกระดับ |
| **LDL Target** | <70 mg/dL | **<55 mg/dL** + PCSK9i เป็น Class I | ⬇️ เข้มข้นขึ้น |
| **Complete Revascularization** | Class IIb | ยก class เป็น **IIa** | ⬆️ ยกระดับ |
| **Radial Access** | Class IIa | ยก class เป็น **Class I** | ⬆️ ยกระดับ |
| **IABP in Shock** | Class IIa | ลด class เป็น **IIb** | ⬇️ ลดระดับ |
| **SGLT2i / GLP-1 RA** | ไม่อยู่ใน ACS guideline | เพิ่มเป็น **Class I** ใน ACS + T2DM | 🆕 ใหม่ |
| **Colchicine** | ไม่มี | เพิ่มเป็น **Class IIb** | 🆕 ใหม่ |

## 🧠 Summary — จำให้ขึ้นใจ

```
📌 STEMI    → Primary PCI ≤90 min | ถ้าไม่ได้ → Fibrinolysis แล้ว transfer

📌 NSTEMI   → Risk stratify ก่อน → Very high = cath ≤2h, High = ≤24h

📌 DAPT     → Aspirin + Ticagrelor (preferred) | Duration 12 เดือน

📌 Statin   → High-intensity ทุกราย | Target LDL <55 mg/dL

📌 Access   → Radial first (Class I)

📌 DM+ACS  → เพิ่ม SGLT2i / GLP-1 RA (Class I — 2023 update)
```
