### 🔴 Don't Miss ⚠️

| Diagnosis | Why dangerous | Clue |
|---|---|---|
| **STEMI** | Complete coronary occlusion → Transmural necrosis → Arrhythmia / Cardiogenic shock ("Time is muscle" — 2 ล้านเซลล์/นาที) | เจ็บแน่นรุนแรง + Diaphoresis profuse + ECG: STE ≥ 1mm ใน ≥ 2 contiguous leads |
| **Aortic Dissection** | Intimal tear → False lumen ขยาย → Rupture / Organ malperfusion / Hemopericardium | Tearing pain ขึ้น peak ทันที + ร้าวทะลุหลัง + BP สองแขนต่างกัน > 20 mmHg |
| **Pulmonary Embolism (PE)** | Thrombus อุด Pulmonary A. → ↑PVR → RV failure → Obstructive shock | Sudden dyspnea + Pleuritic pain + ขาบวมข้างเดียว (DVT source) + Hypoxia |
| **Tension Pneumothorax** | Air trap ดัน Mediastinum → ↓Venous return → Obstructive shock | Sudden dyspnea รุนแรง + เสียงหายใจหายข้างเดียว + Tracheal deviation |
| **Cardiac Tamponade** | Pericardial fluid บีบ → Diastolic collapse → ↓CO → Shock | Beck's Triad: Hypotension + JVP โป่ง + Muffled heart sounds |
| **Esophageal Rupture (Boerhaave)** | Full-thickness rupture → Mediastinitis → Sepsis → Death | ปวดรุนแรง *หลัง* อาเจียนอย่างหนัก + Subcutaneous emphysema |

## Key Pertinent +/−

- ✅ **Bilateral arm radiation + Diaphoresis profuse** → Support ACS อย่างมาก
- ✅ **Pain ขึ้น peak ทันที (Thunderclap-like) + ร้าวทะลุหลัง** → Support Aortic Dissection
- ✅ **Immobilization / ผ่าตัด / มะเร็ง + ขาบวมข้างเดียว** → Support PE
- ✅ **เพิ่งเป็น Viral URI + ไข้ + นั่งโน้มตัวไปข้างหน้าแล้วดีขึ้น** → Support Pericarditis
- ❌ **Pointing sign + กดเจ็บ reproducible + สัมพันธ์กับหายใจ** → Against typical ACS (นึกถึง MSK / Pleuritic)
- ❌ **ดีขึ้นชัดเจนเมื่อนั่งโน้มตัวไปข้างหน้า** → Against ACS (→ Pericarditis)
- ❌ **hs-cTn Serial negative ×2 ตาม 0/1h algorithm** → Rule out NSTEMI (ยังต้องประเมิน UA ต่อ)

## PE ที่ต้องทำ

| System | สิ่งที่ต้องตรวจ | Clinical significance |
|---|---|---|
| **Vital Signs + BP Both Arms** | SBP สองแขน, HR, RR, SpO₂, Temp | BP ต่างกัน > 20 mmHg → Dissection; Tachycardia + Hypoxia → PE / PTX / ACS with HF |
| **CVS** | JVP, Heart sounds (S3/S4, murmur), Pericardial friction rub | JVP โป่ง + Muffled sounds → Tamponade; New MR murmur → Papillary muscle rupture; Friction rub → Pericarditis |
| **Respiratory** | Auscultation bilateral, Percussion | เสียงหายใจหาย 1 ข้าง → Pneumothorax; Crepitations → Pulmonary edema จาก ACS |
| **Chest Wall** | Palpation จุดเจ็บ | Reproducible point tenderness → Support MSK (แต่ห้ามใช้ตัดทิ้ง ACS ใน high-risk pt) |
| **Extremities** | ขาบวม/แดง/ร้อน 1 ข้าง, Pulse bilateral | Unilateral DVT → PE; Pulse deficit → Aortic Dissection |

## First-line Investigation

| Investigation | Purpose | Key expected finding |
|---|---|---|
| **12-Lead ECG ⚠️ (ภายใน 10 นาที)** | Rule in STEMI → reperfusion ทันที; ดู ischemic pattern / pericarditis / PE pattern | STEMI: STE ≥1mm ≥2 contiguous leads / New LBBB; NSTE-ACS: ST depression, T-wave inversion; PE: S1Q3T3, Sinus tach; Pericarditis: Diffuse concave STE + PR depression |
| **hs-Troponin I/T (0-hour + Serial)** | Rule in/out NSTEMI ด้วย ESC 0/1h หรือ 0/2h algorithm | NSTEMI: > 99th percentile URL หรือ delta change เกิน threshold; Rule out: absolute ต่ำ + delta น้อย |
| **Chest X-Ray (PA / Portable)** | ดู Widened mediastinum, Pneumothorax, Pulmonary edema, Pleural effusion | Dissection: mediastinum > 8 cm; HF: Kerley B lines, Bat-wing; PTX: Absent lung markings |
| **SpO₂ ± ABG** | ประเมิน respiratory failure, หา hypoxia | PE: Hypoxia + Hypocapnia; Tension PTX: Severe hypoxia refractory |
| **BP Both Arms (Clinical)** | Rule out Aortic Dissection | ต่างกัน > 20 mmHg → สงสัย Dissection สูง |
| **D-Dimer** | Rule out PE ถ้า pre-test probability ต่ำ (Wells < 2) | Negative + Low PTP → Rule out PE (Sensitivity ~97%) |
| **Bedside Echo (POCUS)** | Wall motion abnormality, Pericardial effusion, RV strain, Aortic root | ACS: Regional WMA; Tamponade: Effusion + RV diastolic collapse; PE: D-shaped LV, RV dilation |
| **CT Aortography** | Confirm/Rule out Aortic Dissection ถ้า clinical suspicious | Type A: Ascending aorta involved → Emergency surgery; Type B: Descending → Medical Mx |
| **CTPA** | Confirm PE ถ้า D-dimer positive หรือ High PTP | Filling defect ใน pulmonary artery |

> ### ⚡ Key Teaching Point
> **ECG ภายใน 10 นาทีแรก = Single most important test ใน Acute Chest Pain**
> เพราะ STEMI คือ time-critical diagnosis — ทุก 1 นาทีที่ delay reperfusion
> = Cardiomyocytes ตายเพิ่ม ~2 ล้านเซลล์
>
> **"Time is Muscle"**
>
> STEMI → Door-to-Balloon **< 90 นาที** (Primary PCI)
> ถ้าทำ PCI ไม่ได้ใน 120 นาที → **Fibrinolysis** แทน
