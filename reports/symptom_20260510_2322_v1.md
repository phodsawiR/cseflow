## Characterize — ต้องถามอะไร

> ⚠️ *ไม่มี Symptom Map ใน input — section นี้ construct จาก standard headache characterization approach*

**SOCRATES + Headache-specific questions:**

| Domain | คำถาม |
|---|---|
| Site | ปวดข้างเดียวหรือสองข้าง? ปวดตำแหน่งไหนของศีรษะ? |
| Onset | เริ่มปวดทันทีหรือค่อย ๆ ปวด? ครั้งแรกเมื่อไหร่? |
| Character | ปวดตุบ ๆ / ปวดหนัก / ปวดรัด / ปวดแปลบ? |
| Radiation | ปวดร้าวไปคอ ตา หรือใบหน้าหรือไม่? |
| Associated Sx | คลื่นไส้ อาเจียน? แสงรบกวน? เสียงรบกวน? มีอาการนำ (aura) หรือไม่? |
| Timing | ปวดนานแค่ไหนต่อครั้ง? ปวดบ่อยแค่ไหนต่อเดือน? |
| Exacerbating | ออกกำลังกายทำให้แย่ลงไหม? ท่าทาง? ไอ/เบ่ง? |
| Relieving | ยาอะไรที่ใช้? ใช้บ่อยแค่ไหน (วัน/เดือน)? ได้ผลไหม? |
| Severity | NRS 0–10? ทำให้หยุดกิจกรรมไหม? |
| **SNOOP4 Red flags** | Thunderclap? Progressive worsening? Fever/neck stiffness? Neurological deficit? Age >50 onset? Positional? Papilledema? |

## DDx Flowchart

### 🟢 Likely

| Diagnosis | Must Ask | Red Flag to R/O |
|---|---|---|
| **Migraine Without Aura** | Unilateral? Throbbing? Nausea/photo/phonophobia? Worsened by activity? Duration 4–72 hr? | Neurological deficit, ไม่ response to triptans |
| **Medication-Overuse Headache (MOH)** | ใช้ยาแก้ปวด ≥15 วัน/เดือน? ปวดทุกวันหรือ near-daily? ยาช่วยน้อยลงกว่าแต่ก่อน? | Progressive worsening แม้ลดยา |

---

### 🟡 Possible

| Diagnosis | Must Ask | Red Flag |
|---|---|---|
| **Tension-Type Headache (TTH)** | ปวดรัดสองข้าง? ไม่มี nausea? ไม่แย่ลงกับ activity? | Bilateral + no autonomic features |
| **Migraine With Aura** | มีอาการนำก่อนปวด? เห็นแสงวูบวาบ / ชาแขน / พูดลำบาก ≤60 นาที? | Motor aura → R/O hem
