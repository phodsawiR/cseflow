# 🧪 Chemotherapy Toxicity — Study Guide for Exam

---

## 📊 Master Summary Table

| Toxicity | Mechanism | Antidote / Treatment | Key Fact |
|---|---|---|---|
| **Febrile Neutropenia** | Chemo ทำลาย progenitor cells → Neutrophil หมด pool เร็วที่สุด (lifespan 6–12 ชม.) | G-CSF (Filgrastim) + Broad-spectrum Abx | ANC < 500 = threshold |
| **Tumor Lysis Syndrome** | Massive cell death → ↑ Uric acid, K⁺, PO₄³⁻, ↓ Ca²⁺ | **Prophylaxis:** Allopurinol / **Treatment:** Rasburicase | Rasburicase ห้ามใน G6PD deficiency |
| **Anthracycline Cardiotoxicity** | Drug + Fe³⁺ → Redox cycling → ROS → Mitochondrial damage | **Dexrazoxane** (Fe chelator) | Doxorubicin > 550 mg/m² = danger zone |
| **Extravasation** | Drug รั่วออก vessel → tissue necrosis | Anthracycline → **DMSO** / Vinca/Taxane → **Hyaluronidase** / Cisplatin → **Na-thiosulfate** | เลือก antidote ตาม **ยาที่รั่ว** ไม่ใช่อาการ |
| **CINV — Acute** | Enterochromaffin cells → **Serotonin (5-HT3)** | **Ondansetron** (5-HT3 antagonist) | เกิดใน < 24 ชม. |
| **CINV — Delayed** | Substance P → **NK1 receptor** ใน CNS | **Aprepitant** (NK1 antagonist) | เกิดใน 24–72 ชม. |
| **Irinotecan Diarrhea — Acute** | SN-38 กระตุ้น Muscarinic receptor → Cholinergic syndrome | **Atropine** | เกิดใน < 24 ชม. |
| **Irinotecan Diarrhea — Delayed** | Mucosal damage โดยตรง | **Loperamide** | เกิดใน > 24 ชม. |
| **irAEs** | PD-1 blocked → T cell hyperactivation → Auto-immune attack ต่อ normal tissue | **Corticosteroids** (Prednisolone / Methylprednisolone) | ต้องให้ Steroid ด้วย ไม่ใช่แค่หยุดยา |
| **Oral Mucositis** | Chemo ทำลาย basal keratinocyte → mucosal barrier เสีย | **Cryotherapy** (เฉพาะ 5-FU) / **Palifermin** (KGF) | Oxaliplatin ห้ามใช้ Cryotherapy |
| **VEGF Inhibitor → HTN** | ↓ VEGF → ↓ eNOS → ↓ NO → Vasoconstriction + ↓ capillary density | Antihypertensives | — |
| **L-asparaginase → Hyperglycemia** | ↓ Protein synthesis → ↓ Insulin secretion จากตับอ่อน | Insulin (ถ้าจำเป็น) | — |

## 🩸 Myelosuppression — ทำไม Neutropenia เกิดก่อน?

### Teaching Points

- Chemo ทำลาย **hematopoietic progenitor cells** พร้อมกันทุก lineage ตั้งแต่ Day 0
- Mature cells ในกระแสเลือดจะหมดลงตาม **lifespan ของแต่ละเซลล์**

```
Progenitor ถูกทำลาย (Day 0)
         ↓
Neutrophil  lifespan  6–12 ชม.  → หมด pool เร็วที่สุด ⚡
Platelet    lifespan  5–10 วัน  → หมดช้ากว่า
RBC         lifespan  120 วัน   → หมดช้าที่สุด (anemia จาก chemo มักไม่ acute)
```

- **ANC < 500 cells/mm³** = threshold สำหรับ Febrile Neutropenia
- ผู้ป่วยที่ได้ chemo มา 2 สัปดาห์แล้วไข้ขึ้น → **คิด Febrile Neutropenia ก่อนเสมอ**

## 🔴 Anthracycline Cardiotoxicity

### Teaching Points

```
Anthracycline + Fe³⁺ → Complex → Redox cycling → ROS ↑↑
                                                    ↓
                          Cardiomyocyte มี catalase ต่ำมาก
                          (≠ Hepatocyte ที่มี antioxidant สูง)
                                                    ↓
                          Mitochondrial damage + Lipid peroxidation
                                                    ↓
                          Cardiomyocyte death → Dilated CMP → HFrEF
                          (IRREVERSIBLE — สะสมตาม cumulative dose)
```

- ทำไม Cardiomyocyte เสี่ยงกว่า Hepatocyte?
  - Hepatocyte มี catalase, glutathione peroxidase, SOD **สูง** → neutralize ROS ได้
  - Cardiomyocyte มี catalase **ต่ำมาก** → ROS ไม่ถูก neutralize → cell death

### Cumulative Dose Threshold

| Drug | Safe Limit | ถ้ามี Prior Chest XRT |
|---|---|---|
| Doxorubicin | > **550 mg/m²** | > **350 mg/m²** |

### Dexrazoxane — Mechanism

```
Dexrazoxane (Prodrug)
    → Hydrolysis → Open-ring metabolite (ICRF-198)
    → Chelate Fe³⁺ ก่อนจับกับ Anthracycline
    → ไม่เกิด Anthracycline-Fe complex
    → ไม่มี Redox cycling → ↓ ROS → ↓ Cardiotoxicity
```

> ⚠️ **Dexrazoxane = Fe chelator** ไม่ใช่ antioxidant โดยตรง

## 🟡 Tumor Lysis Syndrome (TLS)

### Teaching Points

- **Allopurinol vs. Rasburicase** ต้องแยกให้ออก

| | Allopurinol | Rasburicase |
|---|---|---|
| **Target** | Xanthine oxidase | Urate oxidase |
| **Effect** | Block การสร้าง uric acid ใหม่ | เปลี่ยน uric acid ที่มีอยู่แล้ว → allantoin |
| **Role** | **Prophylaxis** | **Treatment** (ลด uric ที่สูงอยู่แล้ว) |
| **Contraindication** | — | **G6PD deficiency ⚠️** |

### ทำไม Rasburicase ห้ามใน G6PD deficiency?

```
Rasburicase (Urate oxidase):
Uric acid + O₂ + H₂O → Allantoin + H₂O₂
                                      ↓
                     G6PD deficiency:
                     ↓ NADPH → ↓ Glutathione (reduced form)
                     → ไม่สามารถ neutralize H₂O₂
                     → Oxidative stress → RBC Hemolysis 💥
```

## 🟢 Chemotherapy-Induced Nausea & Vomiting (CINV)

### Teaching Points

```
< 24 ชม. (Acute Phase)
   → Enterochromaffin cells → Serotonin (5-HT3)
   → รักษาด้วย Ondansetron (5-HT3 antagonist)

24–72 ชม. (Delayed Phase)
   → Substance P → NK1 receptor ใน CNS
   → รักษาด้วย Aprepitant (NK1 antagonist)
```

- Substance P เป็น **neuropeptide** ที่ค้างอยู่ใน CNS **นานกว่า** serotonin
- → Delayed CINV เกิดช้าและนานกว่า → ต้องใช้ยาคนละ class

## 🟠 Irinotecan Diarrhea — 2 Mechanisms คนละ Treatment

### Teaching Points

| | Acute (< 24 ชม.) | Delayed (> 24 ชม.) |
|---|---|---|
| **Mechanism** | Muscarinic receptor activation → Cholinergic syndrome | Mucosal damage โดยตรงจาก SN-38 |
| **Symptoms** | ท้องเสีย + น้ำตาไหล + เหงื่อออก + น้ำลายมาก | ท้องเสียเรื้อรัง |
| **Treatment** | **Atropine** (competitive muscarinic antagonist) | **Loperamide** |

## 🔵 Immune-related Adverse Events (irAEs)

### Teaching Points

```
PD-1 ถูก Block (Pembrolizumab/Nivolumab)
         ↓
T cells ไม่ถูกยับยั้งโดย PD-L1 บน normal tissue
         ↓
Auto-reactive T cells activate → "Hyperactive immune state"
         ↓
ทำลาย normal tissue ที่ express PD-L1:
- Colon epithelium  → Colitis (diarrhea)
- Hepatocyte        → Hepatitis (LFT ↑)
- Thyroid cells     → Thyroiditis (TSH ↓ → อาจ ↑ ภายหลัง)
- Pituitary         → Hypophysitis
- Lung              → Pneumonitis
```

- รักษาด้วย **Corticosteroids** → Suppress T cell activation + ↓ IL-2, IFN-γ, TNF-α
- > ⚠️ irAEs ไม่ได้รักษาโดยหยุดยาอย่างเดียว ต้องให้ **immunosuppression** ด้วย

## 🟣 Oral Mucositis

### Teaching Points

**ทำไม Cryotherapy ได้ผลเฉพาะกับ 5-FU?**

```
Oral Cryotherapy (น้ำแข็งในปาก)
         ↓
Vasoconstriction → ↓ Blood flow ไปยัง oral mucosa
         ↓
↓ Drug delivery ในช่วงที่ drug level สูงสุดใน blood
```

- เงื่อนไขสำคัญ: ยาต้องมี **plasma half-life สั้นมาก** เพื่อให้ vasoconstriction ครอบคลุมได้

| Drug | Half-life | Cryotherapy |
|---|---|---|
| **5-FU IV bolus** | ~10–20 นาที (สั้นมาก) | ✅ ได้ผล |
| **Oxaliplatin** | นานกว่า + infuse 2–6 ชม. | ❌ ไม่ได้ผล + กระตุ้น cold-induced neurotoxicity |

**Palifermin Mechanism:**

```
Palifermin = Recombinant KGF (Keratinocyte Growth Factor)
         ↓
จับ FGFR2 บน basal keratinocyte
         ↓
กระตุ้น proliferation + differentiation ของ mucosal epithelial cells
         ↓
ซ่อมแซม mucosal barrier → ลดความรุนแรง mucositis
```

## ⭐ High-Yield Facts — จำให้ขึ้นใจ

- **Neutropenia** onset เร็วสุด เพราะ lifespan แค่ 6–12 ชม. → ANC < 500 = febrile neutropenia threshold
- **Rasburicase** ห้ามใน G6PD deficiency → เพราะผลิต H₂O₂ → oxidative hemolysis
- **Dexrazoxane** = Fe chelator (ไม่ใช่ antioxidant) → ป้องกัน anthracycline-iron complex
- **Trilaciclib** = CDK4/6 inhibitor → หยุด HSC ที่ G₁/S → quiescent → ต้องให้ **IV ก่อน chemo เสมอ**
- **Irinotecan:** Acute → Atropine / Delayed → Loperamide (คนละ mechanism)
- **irAEs** → รักษาด้วย **Corticosteroids** ไม่ใช่แค่หยุดยา
- **Oral Cryotherapy** ใช้ได้เฉพาะ **5-FU** (short half-life) เท่านั้น
- **L-asparaginase** → ↓ protein synthesis → ↓ Insulin → Hyperglycemia
- **Doxorubicin** > 550 mg/m² = cardiotoxicity risk (ลดเหลือ 350 mg/m² ถ้ามี prior XRT)
- **G-CSF และ EPO** ใช้ signal pathway เดียวกัน: **JAK2-STAT5** ต่างกันที่ receptor และ lineage

## ⚠️ Common Mistakes — Year 4

| ❌ ข้อผิดพลาด | ✅ วิธีหลีกเลี่ยง |
|---|---|
| ให้ Rasburicase โดยไม่เช็ค G6PD → hemolysis | **Check G6PD ก่อนเสมอ** โดยเฉพาะในผู้ป่วยเชื้อสายเอเชีย/แอฟริกา |
| สับสน Acute vs. Delayed Irinotecan diarrhea → ให้ยาผิด | **< 24 ชม. = Cholinergic = Atropine** / **> 24 ชม. = Mucosal = Loperamide** |
| คิดว่า G-CSF และ EPO ต่างกัน mechanism ทั้งหมด | ทั้งคู่ใช้ **JAK2-STAT5** ต่างกันแค่ receptor และ lineage |
| คิดว่า Dexrazoxane = antioxidant | Dexrazoxane เป็น **Fe chelator** ป้องกัน complex formation ตั้งแต่ต้น |
| ใช้ Cryotherapy กับ Oxaliplatin | ห้ามทำ — ความเย็นกระตุ้น **cold-induced neurotoxicity** แย่ลง |
| รักษา irAEs ด้วยการหยุดยาอย่างเดียว | ต้องให้ **Corticosteroids** ด้วย เพราะ T cell hyperactivation ยังดำเนินต่อ |
| ลืม timing ของ Trilaciclib | ต้องให้ **IV ก่อน chemo** เสมอ เพราะต้องให้ HSC เข้า quiescent ก่อน |

## ❓ Q&A — Test Your Understanding

---

**Q1:** ผู้ป่วยได้รับ Irinotecan แล้วถ่ายเหลวภายใน 1 ชั่วโมงหลังได้ยา พร้อมกับน้ำตาไหลและเหงื่อออกมาก คุณจะให้ยาอะไร และ mechanism คืออะไร?

> **A:** ให้ **Atropine** ทันที
>
> นี่คือ **Acute Irinotecan Diarrhea** (< 24 ชม.) เกิดจาก Irinotecan/SN-38 กระตุ้น **Muscarinic receptor** → ↑ Acetylcholine → Cholinergic syndrome (ท้องเสีย, น้ำตาไหล, เหงื่อออก, น้ำลายมาก)
>
> Atropine = **competitive muscarinic antagonist** → block ACh ที่ GI tract → อาการหายได้รวดเร็ว
>
> ⚠️ อย่าสับสนกับ **Loperamide** ซึ่งใช้สำหรับ Delayed diarrhea (> 24 ชม.) จาก mucosal injury — คนละ mechanism คนละ treatment

---

**Q2:** ผู้ป่วย ALL กำลังจะเริ่ม chemo อาจารย์สั่ง Rasburicase แต่ lab พบ G6PD deficiency คุณจะทำอย่างไร?

> **A:** **หยุด Rasburicase ทันที** และเปลี่ยนเป็น **Allopurinol** แทน
>
> Mechanism ของปัญหา:
> ```
> Rasburicase: Uric acid + O₂ + H₂O → Allantoin + H₂O₂
>                                                   ↓
>                              G6PD deficiency:
>                              ↓ NADPH → ↓ Glutathione
>                              → ไม่สามารถ neutralize H₂O₂
>                              → Oxidative stress → RBC Hemolysis
> ```
>
> Allopurinol block Xanthine oxidase → ป้องกันการสร้าง uric acid ใหม่ (แต่ไม่ลด uric ที่มีอยู่แล้ว → ต้อง hydrate ผู้ป่วยเพียงพอ)

---

**Q3:** อธิบาย mechanism ที่ทำให้ Cardiomyocyte เสียหายจาก Anthracycline มากกว่า Hepatocyte และ Dexrazoxane ช่วยอย่างไร?

> **A:**
>
> **Cardiomyocyte เสี่ยงกว่าเพราะ:**
> - Anthracycline + Fe³⁺ → Redox cycling → ROS ↑↑
> - Hepatocyte มี catalase, glutathione peroxidase, SOD สูง → neutralize ROS ได้ดี
> - Cardiomyocyte มี **catalase ต่ำมาก** → ROS ไม่ถูก neutralize → Mitochondrial damage → **Dilated CMP → HFrEF (irreversible)**
>
> **Dexrazoxane:**
> ```
> Dexrazoxane → Hydrolysis → ICRF-198
>     → Chelate Fe³⁺ ก่อนจับกับ Anthracycline
>     → ไม่เกิด Anthracycline-Fe complex
>     → ไม่มี Redox cycling → ↓ ROS → ↓ Cardiotoxicity
> ```

**Q4:** ผู้ป่วยได้รับ Pembrolizumab แล้วมา severe diarrhea, LFT สูง และ TSH ต่ำ อธิบาย mechanism และแนวทางรักษา

> **A:** นี่คือ **irAEs** ที่เกิดจาก mechanism เดียวแต่แสดงออกหลาย organ:
>
> ```
> PD-1 ถูก Block → T cells ไม่ถูกยับยั้ง
>         ↓

> - Colon epithelium → Colitis (diarrhea)
> - Hepatocyte       → Hepatitis (LFT ↑)

> ```
>
> **รักษา:** **Corticosteroids** (Prednisolone/Methylprednisolone)

**Q5:** ทำไม Oral Cryotherapy ได้ผลกับ 5-FU แต่ไม่ได้ผลกับ Oxaliplatin และ Palifermin ทำงานอย่างไร?

> ```
> Palifermin = Recombinant KGF
>     → จับ FGFR2 บน basal keratinocyte
>     → กระตุ้น proliferation + differentiation ของ mucosal epithelial cells
>     → ซ่อมแซม mucosal barrier → ลดความรุนแรง mucositis
> ```

## QA Review

**ความเชื่อมั่น:** 🟢 สูง

**⚠️ จุดที่ควรตรวจสอบ:**
- รายงานระบุ Neutrophil lifespan "6–12 ชม." ซึ่งตรงกับ input แต่ควรทราบว่า input ใช้คำว่า "Onset 6-12 ชม." ซึ่งหมายถึง onset ของ neutropenia ไม่ใช่ lifespan จริงของ neutrophil โดยตรง (lifespan จริงของ mature neutrophil คือ ~6–8 ชม. ในกระแสเลือด) — อาจเกิด conceptual confusion เล็กน้อย แต่ไม่ถึงขั้น error ร้ายแรงในบริบทการสอบ
- รายงานกล่าวถึง Doxorubicin threshold "550 mg/m²" และ "350 mg/m² ถ้ามี prior XRT" — ข้อมูลนี้ไม่มีใน input ที่ให้มา อาจเป็น prior knowledge ที่ถูกต้อง แต่ควรตรวจสอบกับ source ต้นฉบับของการเรียน

**🔍 ตรรกะทางคลินิก:**
- Mechanism ของ Palifermin, Dexrazoxane, Rasburicase, irAEs และ CINV อธิบายสอดคล้องกัน ไม่มีข้อขัดแย้ง
- Irinotecan: แยก Acute vs. Delayed ถูกต้อง ครบทั้ง mechanism และ treatment
- Trilaciclib ถูกระบุว่าเป็น CDK4/6 inhibitor หยุดที่ G₁/S — สอดคล้องกับ input (G₁)

**📋 ประเด็นที่ขาด:**
- **Scalp cooling** สำหรับป้องกัน Alopecia — มีใน input แต่ไม่ปรากฏในรายงาน
- **Magic mouthwash** (Lidocaine + Diphenhydramine + Antacid) สำหรับ mucositis — มีใน input แต่ไม่มีในรายงาน
- **Octreotide** สำหรับ delayed diarrhea ที่รุนแรง — มีใน input แต่รายงานกล่าวถึงเฉพาะ Loperamide
- **Platelet transfusion threshold** (< 10,000) และ **Hb threshold** (< 8 g/dL) สำหรับ transfusion — ขาดไป

**💡 คำแนะนำก่อน approve:**
- ตรวจสอบตัวเลข cumulative dose threshold (550/350 mg/m²) กับ slide/textbook ต้นฉบับก่อนจำ
- เนื้อหาครอบคลุมดี เหมาะสำหรับการสอบ science-focused แต่ถ้าต้องการครบสมบูรณ์ ควรเพิ่ม Octreotide และ Magic mouthwash
